# Career Match Case Study Image Placement Guide

All eight PNG assets use transparent backgrounds.

1. `01-career-match-hero-product-ecosystem.png`
   - Best use: case-study hero / opening product visual
   - Shows: desktop + mobile Career Match ecosystem with supporting UI elements

2. `02-career-match-desktop-match-analysis.png`
   - Best use: product experience / current solution
   - Shows: desktop match-analysis experience with resume, role requirements, score, strengths, gaps, and explanation

3. `03-career-match-mobile-match-experience.png`
   - Best use: responsive/mobile product experience or visual break
   - Shows: mobile Career Match match-detail experience with supporting analysis cards

4. `04-career-match-resume-to-opportunity-flow.png`
   - Best use: "Here’s what happens between a resume and a match" / system flow
   - Shows: resume input → extraction → profile → comparison → explanation → recommended roles

5. `05-career-match-keyword-vs-semantic-comparison.png`
   - Best use: problem / baseline limitations / transition to semantic matching
   - Shows: traditional keyword matching versus semantic Career Match behavior

6. `06-career-match-semantic-matching-system.png`
   - Best use: semantic matching explanation
   - Shows: resume representation + job representation flowing through semantic comparison into match output

7. `07-career-match-stress-test-stuffing-negation.png`
   - Best use: "The numbers looked good. So I tried to break it." / stress testing
   - Shows: keyword stuffing and negation failure cases

8. `08-career-match-benchmark-results.png`
   - Best use: evaluation / benchmark results
   - Shows: MiniLM v0.2 synthetic-development benchmark metrics and benchmark composition

## Usage notes
- Do not place all images back-to-back.
- Let each visual answer one part of the story.
- Keep surrounding case-study text separate from the image; do not add headline overlays on top of these PNGs unless composition requires it.
- Preserve transparency and avoid putting the images inside generic rounded cards.
- Use generous negative space and asymmetric placement consistent with the portfolio's editorial direction.
